OBS Studio & GStreamer WebRTC Setup

How the WebRTC Stream Works

This viewer connects to the obs-gstreamer plugin in OBS Studio via the standard WHEP (WebRTC HTTP Egress Protocol) protocol.

1. Configure OBS Studio Output

In OBS Studio, configure the GStreamer output with WebRTC enabled:

  • Output Type: GStreamer WebRTC
  • HTTP Port: 8888 (default)
  • Web Root: .webrtc-webroot

2. GStreamer Encoder Pipeline Example

Hardware accelerated low-latency H.264 encoding pipeline:

x264enc tune=zerolatency speed-preset=veryfast bitrate=3000 bframes=0 cabac=false key-int-max=30 ! video/x-h264, profile=constrained-baseline, stream-format=byte-stream ! h264parse config-interval=-1 ! rtph264pay name=pay0 pt=102 config-interval=-1

3. Start Streaming

When you click Start Output in OBS, the built-in HTTP server begins listening on port 8888. This monitor will immediately auto-detect the stream, perform the WebRTC handshake via WHEP, and begin ultra-low latency playback.
