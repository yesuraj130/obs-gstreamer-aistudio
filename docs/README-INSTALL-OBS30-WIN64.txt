=============================================================
obs-gstreamer for OBS Studio 28+ / 30+ (64-bit / Windows 10/11)
Target: x86_64 (64-bit)
=============================================================

Prerequisites:
1. Official 64-bit GStreamer Runtime (MinGW 1.22.x or MSVC 1.22+ x64):
   https://gstreamer.freedesktop.org/data/pkg/windows/
   * Ensure the GStreamer bin folder (e.g. C:\gstreamer\1.0\msvc_x86_64\bin or mingw_x86_64\bin) is in PATH.
2. OBS Studio 28, 29, or 30+ (64-bit).

Installation:
Copy 'obs-plugins/64bit/obs-gstreamer.dll' into your OBS Studio 64-bit plugin folder:
C:\Program Files\obs-studio\obs-plugins\64bit\obs-gstreamer.dll
